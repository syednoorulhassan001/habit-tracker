# Habit Tracker

A simple, fast habit tracker. Add habits, check them off each day, and watch your streaks grow.

## Features (planned)

- Add and remove habits
- Daily check-ins
- Current and best streaks
- Completion stats
- Dark mode
- Data saved locally in your browser

## Tech stack

- React
- Vite
- localStorage for persistence

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |
